# Установка Telegram Lead Radar на сервер

Установщик рассчитан на чистый Ubuntu/Debian-сервер. Он устанавливает Docker при
необходимости, генерирует секреты, создаёт Argon2-хеш пароля, собирает контейнеры,
применяет миграции и запускает приложение.

## Перед установкой

- Направьте A-запись домена на публичный IP сервера — тогда Caddy автоматически
  выпустит HTTPS-сертификат.
- Откройте входящие TCP-порты 22, 80 и 443, а также UDP 443.
- Не добавляйте `.env` в Git. Он исключён через `.gitignore`.

## Одна команда после загрузки исходников

```bash
sudo bash install.sh
```

Установщик спросит домен/IP и пароль администратора. Если оставить пароль пустым,
он будет сгенерирован и показан один раз в конце.

Если репозиторий публичный, клонирование и установка объединяются в одну команду:

```bash
git clone URL_РЕПОЗИТОРИЯ lead-radar && cd lead-radar && sudo bash install.sh
```

Полностью автоматический вариант без вопросов (замените значения своими):

```bash
sudo env PUBLIC_HOST=radar.example.com ADMIN_PASSWORD='надежный-пароль' bash install.sh
```

При указании домена приложение откроется на `https://домен`. При указании IP будет
использован `http://IP`; этот режим подходит для первичной проверки, но не защищает
данные при передаче.

## После установки

1. Откройте показанный установщиком адрес.
2. Войдите с выбранным или сгенерированным паролем.
3. Откройте «Настройки» и подключите Telegram через встроенный мастер.
4. Там же подключите бота уведомлений: вставьте токен от `@BotFather`, отправьте
   созданному боту `/start`, найдите чат и сохраните подключение.
5. Добавьте группы и каналы в «Источники».
6. Создайте профили поиска и включите в них уведомления.
7. В «Настройках» подключите настоящий AI-провайдер. Тестовый режим подходит
   только для проверки интерфейса и не обеспечивает точной классификации.
8. Заполните «Мой профиль» и добавьте реальные кейсы, чтобы радар мог формировать
   блок «Что приложить» без выдуманных ссылок.
9. Выберите мгновенные уведомления, дайджест или комбинированный режим.

## Обновление

Если код обновляется через Git:

```bash
sudo bash update.sh --pull
```

Если новые исходники копируются на сервер вручную:

```bash
sudo bash update.sh
```

Миграции применяются backend-контейнером автоматически. PostgreSQL, Telegram-сессия
и зашифрованные credentials находятся в Docker volumes и при обновлении сохраняются.

## Управление

```bash
# Состояние
docker compose -p lead-radar -f docker-compose.prod.yml ps

# Логи backend
docker compose -p lead-radar -f docker-compose.prod.yml logs -f backend

# Перезапуск
docker compose -p lead-radar -f docker-compose.prod.yml restart

# Остановка без удаления данных
docker compose -p lead-radar -f docker-compose.prod.yml down
```

Не запускайте `down -v`, если хотите сохранить базу, Telegram-сессию и сертификаты.

## Резервное копирование

Создать SQL-копию базы в текущей папке:

```bash
docker compose -p lead-radar -f docker-compose.prod.yml exec -T postgres \
  pg_dump -U lead_radar lead_radar > lead-radar-backup.sql
```

Зашифрованные Telegram, Bot API и AI credentials находятся в Docker volume
`lead-radar_telegram_sessions`. Архивировать его можно так:

```bash
docker run --rm \
  -v lead-radar_telegram_sessions:/data:ro \
  -v "$PWD":/backup alpine \
  tar czf /backup/lead-radar-credentials.tar.gz -C /data .
```

Храните SQL-файл и архив credentials вместе с `APP_SECRET_KEY` из `.env`. Без этого
ключа зашифрованные данные восстановить невозможно. Не публикуйте резервные копии в Git.

## Готовая настройка поиска заказов

В репозитории находится идемпотентный набор маркетинговых настроек для поиска заказов
на сайты, дизайн, Telegram-ботов, CRM, автоматизацию и AI. Перед применением скрипт
автоматически создаёт полный SQL-бэкап базы в закрытой папке `backups/`:

```bash
sudo bash apply-marketing-setup.sh
```

Команду можно запускать повторно. Она обновляет только общие параметры, профили поиска,
поисковые запросы и пустые поля «Моего профиля». Telegram-сессия, AI и Bot API keys,
источники, сообщения, лиды, реальные кейсы и уже заполненные данные профиля сохраняются.

## Повторная настройка адреса или пароля

```bash
sudo bash install.sh --reconfigure
```

Существующие пароль PostgreSQL и `APP_SECRET_KEY` при этом сохраняются, поэтому база
и зашифрованная Telegram-сессия остаются читаемыми.
